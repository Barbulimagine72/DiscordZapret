> WinDivert применяется как безопасными, так и вредоносными программами, однако сам по себе вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы определяют файлы WinDivert как инструменты повышенного риска или хакерские утилиты, после чего удаляют их либо помещают в карантин. В названии такого срабатывания обязательно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Можно добавить папку с запретом в исключения антивируса либо отключить обнаружение PUA — потенциально нежелательных приложений. Например, в Касперском предусмотрена настройка «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». Если вы уверенно настраиваете исключения, рекомендуется добавить исключение. Если не до конца понимаете свои действия, лучше отключить обнаружение PUA.

## ⚙️Как пользоваться

1. Настройте Безопасный DNS (Secure DNS)
    * Chrome: включите «Использовать безопасный DNS» и укажите поставщика DNS, отличного от варианта «Поставщик по умолчанию»
    * Firefox: откройте «DNS через HTTPS», установите режим «Персональный», затем нажмите «Выбрать провайдера/поставщика» и вручную добавьте URL поставщика. Например, подойдёт `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет активировать Secure DNS непосредственно в параметрах ОС — [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Этот способ рекомендуется пользователям Windows 11
    * Владельцам роутеров Keenetic нужно включить параметр «Транзит запросов». Если он отключён, при настройке и использовании Secure DNS на компьютере могут возникать проблемы

2. Откройте [страницу актуального релиза](https://github.com/Barbulimagine72/zapret-discord-youtube/releases/latest) и загрузите архив zip/rar

3. Перейдите в свойства загруженного архива и отметьте пункт «Разблокировать». При использовании 7-Zip или PeaZip выполнять этот шаг не требуется

4. Извлеките файлы в каталог, путь к которому не включает кириллицу и специальные символы

5. Запустите подходящий файл
    * Чтобы определить рабочую стратегию: **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`
    * Чтобы настроить автозапуск: **`service.bat`** → `Install Service` → *выберите подходящую стратегию*

## ℹ️Назначение файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск подходит для проверки стратегий. Их работоспособность зависит от множества условий. **Перебирайте разные варианты — ALT, FAKE и другие, — пока не найдёте решение, которое работает у вас**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные инструменты:
  - <ins>**`Install Service`** — добавляет выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** — удаляет стратегию и WinDivert из списка служб
  - **`Check Status`** — показывает состояние обхода и служб: стратегии в автозапуске и WinDivert
  - **`Game Filter`** — меняет режим обхода для игр и других сервисов, работающих по UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  Текущее состояние — включено или выключено — отображается в скобках.
  - **`IPSet Filter`** — управляет режимом обхода сервисов, перечисленных в `ipset-all.txt`.  
  Опция пригодится при тестировании, если ресурс доступен без zapret, но не работает вместе с ним.  
  В скобках показывается один из текущих режимов:
    - `none` — IP-адреса не проверяются
    - `loaded` — проверяется наличие IP-адреса в списке
    - `any` — под фильтрацию попадает любой IP-адрес  
  - **`Auto-Update Check`** — включает или выключает автоматическую проверку обновлений
  - **`Replace active fakes`** — заменяет указанный активный фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** — загружает в `ipset-all.txt` актуальный список из репозитория
  - **`Update Hosts File`** — обновляет hosts <ins>**для восстановления работы веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — ищет доступные обновления
  - **`Run Diagnostics`** — проверяет распространённые причины неработоспособности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`: это иногда помогает, если приложение внезапно перестало работать
  - **`Run Tests`** — запускает средство проверки стратегий:
    - `Standard tests` — тестирует сайты, перечисленные в `utils/targets.txt`
    - `DPI checkers` — проверяет DPI через разных провайдеров, включая Cloudflare, Amazon и других


## ☑️Частые вопросы и неполадки

### После открытия скрипта `general*` ничего не происходит

При ручном запуске стратегии отдельным bat-файлом, а не через service, должен открыться winws.exe — процесс обхода, отображаемый на панели задач.  
Если он не появился, ознакомьтесь с [#522](https://github.com/Barbulimagine72/zapret-discord-youtube/issues/522).

### Не удаётся подобрать рабочую стратегию
- Откройте командную строку с правами администратора
- По очереди выполните следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер

### Не открывается веб-версия Telegram
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если ваш hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из запущенного Блокнота
  - В появившемся каталоге найдите `hosts` и откройте его текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный фрагмент в конец файла `hosts`; если похожие записи уже добавлялись, замените их
  - Сохраните файл и снова проверьте соединение. Если результата нет, убедитесь, что изменения в `hosts` действительно сохранились

#### Работоспособность этого способа не гарантируется. Если он не помог, установите [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) и используйте [локальный прокси](https://github.com/Barbulimagine72/tg-ws-proxy) либо любой публичный прокси.

### Обход перестал работать или не запускался изначально

> [!IMPORTANT]
> **Со временем отдельные стратегии могут терять работоспособность.**
> Конкретный вариант способен работать в течение некоторого периода, а затем перестать из-за обнаружения.
> Репозиторий содержит много разных стратегий обхода. Если ни одна не подходит, создайте новую: возьмите за основу один из имеющихся вариантов и измените его параметры.
> Описание параметров стратегий доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` → `Run Diagnostics` и убедитесь, что диагностика не сообщает об ошибках

- Проверьте, присутствует ли адрес нужного ресурса в списках доменов или IP

- Испытайте остальные стратегии, включая **`ALT`**, **`FAKE`** и другие

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/Barbulimagine72/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезапустите устройство
- Выполните `service.bat` → `Remove Services`
- Запустите `service.bat` → `Run Diagnostics`; исправьте найденные ошибки и в конце выберите Y
- Удалите папку с запретом
- Загрузите свежую версию (`zapret-discord-youtube-...`) [со страницы релизов](https://github.com/Barbulimagine72/zapret-discord-youtube/releases)
- Щёлкните по архиву правой кнопкой мыши и откройте свойства. Если внизу справа есть флажок «Разблокировать», установите его, затем нажмите «Применить» и «ОК»
- Распакуйте архив в новый каталог в корне диска; путь не должен содержать пробелы и специальные символы
- Поочерёдно запускайте разные скрипты `general`, то есть стратегии. Проверяйте доступность интернет-ресурсов. Если они не открываются, закройте программу через значок замка на панели задач и попробуйте следующую стратегию
- Найденный рабочий вариант можно добавить в автозапуск: `service.bat` → `Install Service` → выберите нужную стратегию

### При включённом запрете не запускается игра или приложение

- Убедитесь, что в `service.bat` для `Game Filter` задано **`disabled`**, а для `IPSet Filter` — **`none`**. Другие значения могут неожиданно повлиять на доступность ресурсов.

### Античит обнаруживает WinDivert

- Следуйте инструкции по адресу: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) служба WinDivert не исчезла

1. Откройте командную строку Windows через Win+R → `cmd` и определите имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Выключите блокировщик рекламы: известно, что YouTube начал бороться с такими расширениями
- Переберите остальные стратегии, в том числе если ранее всё работало
- Также ознакомьтесь с [#251](https://github.com/Barbulimagine72/zapret-discord-youtube/discussions/251)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Удостоверьтесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Сначала желательно определить стратегию, с которой открывается YouTube, и запустить именно её
- Перейдите в `service.bat` → `Run Diagnostics` и очистите кэш Discord
- Снова проверьте приложение Discord и выясните, помогло ли удаление кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ею
- Если Discord недоступен и в браузере, повторно проверьте все стратегии. Иногда одна стратегия открывает YouTube, но не Discord
- Дополнительные сведения есть в [#252](https://github.com/Barbulimagine72/zapret-discord-youtube/discussions/252)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/Barbulimagine72/tg-ws-proxy)
- Другой вариант — бесплатные MTProto-прокси из интернета

### Возникают проблемы с играми

Игр существует очень много, поэтому исследовать и исправлять работу каждой из них нет возможности.

Наиболее универсальная последовательность действий:
- обновите ipset через `service.bat`, затем включите `Game Filter`
- если результата нет, дополнительно активируйте режим `ipset any`

Учтите, что `ipset any` вызывает проблемы с открытием многих сайтов. Не оставляйте этот режим включённым постоянно. Вместо этого определите все IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`.

Если рекомендации не помогли, создайте тему в разделе [Discussions](https://github.com/Barbulimagine72/zapret-discord-youtube/discussions), а не в issues, и дождитесь помощи других игроков.

### Нужной проблемы нет в списке

- Сообщите о ней [здесь](https://github.com/Barbulimagine72/zapret-discord-youtube/issues)

## 🗒️Как добавить адреса других ресурсов

Расширить перечень адресов для обхода можно через следующие файлы:
- **`list-general-user.txt`** — домены; их поддомены учитываются автоматически
- **`list-exclude-user.txt`** — исключения доменов, например когда IP сети присутствует в `ipset-all.txt`, но отдельный домен из этой сети фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — исключения IP-адресов и подсетей
  - Файлы вида **`*-user.txt`** будут созданы автоматически при первом запуске `zapret` или `service.bat`
