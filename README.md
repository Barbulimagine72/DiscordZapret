> ### РЕАКЦИЯ АНТИВИРУСОВ
> Антивирус может среагировать на WinDivert.  
> Для работы zapret требуется WinDivert — средство перехвата и фильтрации сетевого трафика.
> Его способны применять как безопасные, так и вредоносные программы, однако сам инструмент вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Ряд антивирусов определяет файлы WinDivert как ПО повышенного риска либо хакерские инструменты, после чего удаляет их или отправляет в карантин. Название такого детекта обязательно содержит `WinDivert` либо выглядит как `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Можно добавить папку с zapret в исключения антивируса или выключить обнаружение PUA — потенциально нежелательных приложений. Например, в Касперском для этого предусмотрена настройка «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». Если вы уверенно настраиваете исключения, рекомендуется добавить исключение; если не вполне понимаете свои действия — лучше отключить обнаружение PUA.

## ⚙️Как пользоваться

1. Активируйте Безопасный DNS (Secure DNS)
    * В Chrome включите «Использовать безопасный DNS» и укажите DNS-сервис, отличный от варианта «Поставщик по умолчанию»
    * В Firefox откройте «DNS через HTTPS», установите режим «Персональный», затем нажмите «Выбрать провайдера/поставщика» и вручную задайте его URL. Подойдёт, например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет настроить Secure DNS средствами самой ОС — воспользуйтесь [этой инструкцией](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 это рекомендуемый способ
    * Владельцам роутеров Keenetic необходимо активировать параметр «Транзит запросов». Если он отключён, при настройке и использовании Secure DNS на компьютере возможны проблемы

2. Загрузите архив zip/rar со [страницы актуального релиза](https://github.com/Barbulimagine72/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и отметьте пункт «Разблокировать». При работе через 7-Zip или PeaZip выполнять это действие не требуется

4. Извлеките архив в каталог, путь к которому не включает кириллицу и специальные символы

5. Откройте подходящий файл
    * Найти рабочую стратегию: **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`
    * Настроить автозапуск: **`service.bat`** → `Install Service` → *выберите подходящую стратегию*

## ℹ️Что делают файлы

- [**`general.bat ...`**](./general.bat) — ручной запуск выбранной стратегии

  Такой запуск удобен для проверки стратегий: их работоспособность определяется множеством условий. **Перебирайте варианты ALT, FAKE и остальные стратегии, пока не найдёте решение, подходящее именно вам**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные возможности:
  - <ins>**`Install Service`** — добавляет выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** — убирает стратегию и WinDivert из списка служб
  - **`Check Status`** — показывает состояние обхода и служб: стратегии в автозапуске и WinDivert
  - **`Game Filter`** — меняет режим обхода для игр и иных сервисов, работающих по UDP и TCP на портах выше 1023.  
  **Чтобы изменение применилось, перезапустите стратегию.**  
  Текущее состояние — включено или выключено — отображается в скобках.
  - **`IPSet Filter`** — выбирает режим обхода ресурсов, перечисленных в `ipset-all.txt`.  
  Пригодится во время тестирования, когда ресурс доступен без zapret, но не работает вместе с ним  
  В скобках показывается активный режим:
    - `none` — IP-адреса не проверяются
    - `loaded` — проверяется наличие IP-адреса в списке
    - `any` — фильтрация применяется к любому IP-адресу  
  - **`Auto-Update Check`** — включает или отключает автоматический поиск обновлений
  - **`Replace active fakes`** — меняет указанный активный фейк на другой файл из каталога `bin`
  - **`Update IPSet List`** — загружает в `ipset-all.txt` свежий список из репозитория
  - **`Update Hosts File`** — обновляет hosts <ins>**для восстановления веб-версии Telegram и соединения с голосовым чатом Discord**</ins>
  - **`Check for Updates`** — ищет доступные обновления
  - **`Run Diagnostics`** — проверяет распространённые причины неработоспособности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`: это иногда помогает, если приложение внезапно перестало подключаться
  - **`Run Tests`** — открывает средство тестирования стратегий:
    - `Standard tests` — тестирует адреса из `utils/targets.txt`
    - `DPI checkers` — проверяет DPI через разных провайдеров, включая Cloudflare, Amazon и другие


## ☑️Частые вопросы и неполадки

### Скрипт `general*` запускается, но ничего не происходит

- При ручном запуске стратегии отдельным bat-файлом, а не через service, должен появиться winws.exe — процесс обхода, видимый на панели задач.  
Если процесс не появился, ознакомьтесь с [#522](https://github.com/Barbulimagine72/zapret-discord-youtube/issues/522)

### Не удалось подобрать рабочую стратегию
- Откройте командную строку с правами администратора
- По очереди выполните следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Затем перезагрузите компьютер

### Не открывается веб-версия Telegram
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если установленный hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте целиком содержимое открывшегося документа в блокноте
  - В появившемся каталоге откройте `hosts` текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный текст в конец `hosts` либо замените ранее добавленный аналогичный блок
  - Сохраните изменения и снова проверьте соединение. Если результата нет, удостоверьтесь, что файл `hosts` действительно был сохранён.

#### Результат не гарантируется. Если способ не сработал, установите [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) и подключите [локальный прокси](https://github.com/Barbulimagine72/tg-ws-proxy) либо любой публичный.

### Обход не запускается или больше не помогает

> [!IMPORTANT]
> **Любая стратегия со временем может утратить работоспособность.**
> Выбранный вариант способен успешно работать некоторое время, а затем перестать из-за обнаружения.
> В этом репозитории собрано множество способов обхода. Когда ни один из них не подходит, создайте собственную стратегию: возьмите за основу одну из имеющихся и скорректируйте параметры.
> Описание параметров стратегий доступно [по этой ссылке](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` → `Run Diagnostics` и убедитесь в отсутствии ошибок

- Проверьте, присутствует ли адрес нужного ресурса в перечне доменов или IP

- Испытайте остальные стратегии, в том числе **`ALT`**, **`FAKE`** и другие

- Выполните полную переустановку по инструкции из следующего раздела

- Дополнительная информация приведена в [#765](https://github.com/Barbulimagine72/zapret-discord-youtube/issues/765)

### Как выполнить полное обновление или переустановку?
- Сделайте копию ресурсов и данных, добавленных вами вручную
- Перезагрузите устройство
- Вызовите `service.bat` → `Remove Services`
- Выполните `service.bat` → `Run Diagnostics`, исправьте найденные ошибки и в конце нажмите Y
- Удалите каталог с zapret
- Загрузите актуальную версию (`zapret-discord-youtube-...`) [на странице релизов](https://github.com/Barbulimagine72/zapret-discord-youtube/releases)
- Щёлкните архив правой кнопкой мыши и откройте свойства. Если справа внизу доступна отметка «Разблокировать», установите её, нажмите «Применить», а затем «ОК»
- Распакуйте файлы в новый каталог в корне диска; его путь не должен содержать пробелы и специальные символы
- Поочерёдно запускайте разные скрипты `general`, то есть стратегии, и проверяйте доступ к интернет-ресурсам. Если вариант не работает, закройте программу через значок замка на панели задач и испытайте следующий
- Обнаружив рабочую стратегию, добавьте её в автозапуск: `service.bat` → `Install Service` → выберите нужный вариант

### Игра или приложение недоступны при активном zapret

- Убедитесь, что в service.bat параметр `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Другие значения способны неожиданно повлиять на доступность ресурсов.

### Античит обнаруживает WinDivert

- Следуйте инструкции по адресу https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените расположенные в [`bin`](./bin) файлы `WinDivert.dll` и `WinDivert64.sys` одноимёнными версиями из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) служба WinDivert не исчезает

1. В командной строке Windows, открытой через Win+R и `cmd`, определите имя службы командой:

```cmd
driverquery | find "Divert"
```

2. Завершите работу службы и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте правильность настройки [Secure DNS](#%EF%B8%8Fиспользование)
- Выключите блокировщик рекламы: известно, что YouTube начал противодействовать таким расширениям.
- Проверьте все остальные стратегии, особенно если ранее доступ был, а затем пропал.
- Дополнительные сведения есть в [#251](https://github.com/Barbulimagine72/zapret-discord-youtube/discussions/251)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Сначала убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Желательно определить стратегию, с которой открывается YouTube, и запустить именно её.
- Откройте `service.bat` → `Run Diagnostics` и очистите кэш Discord.
- После очистки проверьте, заработало ли приложение Discord.
- Откройте https://discord.com/app в браузере. Если веб-версия доступна, можно пользоваться ею.
- Когда Discord не работает даже в браузере, снова переберите все стратегии: некоторые варианты открывают YouTube, но не Discord.
- Другие рекомендации собраны в [#252](https://github.com/Barbulimagine72/zapret-discord-youtube/discussions/252)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь приложением [tg-ws-proxy](https://github.com/Barbulimagine72/tg-ws-proxy)
- Другой вариант — бесплатные публичные MTProto-прокси из интернета

### Игры остаются недоступны

Игр слишком много, поэтому исследовать и исправлять работу каждой отдельно невозможно.

Наиболее универсальная последовательность действий:
- обновите ipset через `service.bat`, после чего активируйте `Game Filter`
- если результата нет, дополнительно попробуйте режим `ipset any`

Учтите: `ipset any` способен нарушить доступ ко многим сайтам, поэтому не оставляйте этот режим включённым постоянно. Вместо этого определите все IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`

Если перечисленные действия не помогли, создайте тему в разделе [Discussions](https://github.com/Barbulimagine72/zapret-discord-youtube/discussions), а не в issues, и дождитесь подсказок других игроков.

## 🗒️Как добавить адреса других ресурсов

Чтобы расширить перечень адресов для обхода, используйте следующие файлы:
- **`list-general-user.txt`** — домены; их поддомены будут учтены автоматически
- **`list-exclude-user.txt`** — исключения доменов, например когда сеть присутствует в `ipset-all.txt`, но отдельный домен внутри неё фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — исключаемые IP-адреса и подсети
  - Документы **`*-user.txt`** создаются автоматически во время первого запуска `zapret` либо `service.bat`
